Интеллектуальная система прогнозирования и оптимизации налоговых отчислений для малого бизнеса.

Программный комплекс позволяет вести учет доходов, прогнозировать будущие налоговые обязательства с использованием методов математического сглаживания и выбирать оптимальный налоговый режим (УСН 6% vs УСН 15%).

🛠 Технологический стек
Backend: Python 3.13, FastAPI.

Database: SQLite + SQLAlchemy (ORM).

Math & Analytics: Экспоненциальное сглаживание (EMA), детерминированные алгоритмы расчета.

Frontend: HTML5, JavaScript (Async/Await), Chart.js (визуализация).

🚀 Инструкция по запуску
1. Клонирование репозитория
Bash
git clone https://github.com/твой_логин/tax-prediction-fastapi.git
cd tax-prediction-fastapi
2. Настройка виртуального окружения
Bash
python3 -m venv venv
source venv/bin/activate  # Для macOS/Linux
# venv\Scripts\activate  # Для Windows
3. Установка зависимостей
Bash
pip install -r requirements.txt
4. Запуск сервера
Bash
uvicorn main:app --reload
После запуска:

Интерфейс: Откройте файл index.html в браузере (или через Live Server).

Интерактивная документация (Swagger): http://127.0.0.1:8000/docs

🧠 Интеллектуальные функции
EMA Smoothing: Алгоритм автоматически сглаживает случайные всплески доходов, выявляя реальный тренд для точного прогноза.

Tax Optimizer: Система сравнивает две налоговые модели и предлагает режим с минимальной выплатой, рассчитывая потенциальную экономию.

Validation: Интегрированная проверка данных через Pydantic исключает ввод некорректных сумм.

📂 Структура проекта
main.py — Точка входа, логика API и алгоритмы расчета.

models.py — Описание таблиц базы данных (SQLAlchemy).

schemas.py — Схемы валидации данных (Pydantic).

crud.py — Функции взаимодействия с БД.

database.py — Конфигурация подключения к SQLite.

tax_app.db — Файл базы данных (генерируется автоматически).
