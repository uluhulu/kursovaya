# 📊 АИС «Налоговый Прогноз 2026»

**Интеллектуальная информационная система для прогнозирования и оптимизации налоговых отчислений.**

Данный проект представляет собой систему поддержки принятия решений (СППР) для малого бизнеса и самозанятых. Система не только ведет учет доходов, но и анализирует финансовые тренды, предсказывая будущую налоговую нагрузку и предлагая наиболее выгодный налоговый режим.

---

## 🌟 Ключевые особенности

* **Интеллектуальный прогноз (EMA):** Использование метода экспоненциального сглаживания для фильтрации случайных колебаний дохода и выявления реального тренда.
* **Налоговая оптимизация:** Автоматическое сравнение режимов **УСН 6%** (Доходы) и **УСН 15%** (Доходы минус расходы).
* **Детерминированный расчет:** Прямое вычисление налогов на основе актуальных ставок налогового законодательства РФ.
* **Интерактивная визуализация:** Построение графиков фактических и прогнозных данных с помощью *Chart.js*.
* **Современный стек:** Полностью асинхронный бэкенд на FastAPI с валидацией данных через Pydantic.
